# Public baseline changes

This baseline changes operational configuration loading, repository identity and release guards, build setup and documentation. Installation-specific identities and acceptance records are supplied through an administrator-owned configuration rather than source constants. Tests use explicit synthetic data.

The Solana program, instruction ABI and economic semantics are unchanged. The source-visible facilitator, paid-report application, browser wallet integration, recovery tools and operator controllers remain included. Public documentation describes reproducible checks and limits; it does not claim a live deployment or current production acceptance.

The browser presentation uses public source references and local verification instructions. CI rebuilds the program from source and can be dispatched manually for critical validation. Mandatory source and bundled dependency notices are retained.

An unconfigured loopback presentation entrypoint requires no installed acceptance data and has no economic backend. Deployment launch verifies numeric public repository identity before remote effects and refuses Git redirects. Quarantine uses the canonical fixed deployment record path. Isolation archives use explicitly approved restaurant custody and preserve the original UNKNOWN records and reservations on any failure. Disposable Linux checks cover real systemd, syscall faults and non-default archive ownership.
